# 作为作品集使用

本项目的定位是**本地演示 + 代码仓库**，不公开部署服务。

!!! info "为什么不公开部署"
    原因见 `portfolio.md`：文档授权与 ICP / AI 备案成本。
    更具体地说：公开提供文档检索属于信息网络传播行为，需要确认授权范围；
    同时国内网站在线服务涉及备案成本。因此本项目选择"可本地复现 + 代码公开"的路线。

## 发布前检查流程

```bash
python scripts/publish_check.py
```

它会检查：

1. **密钥泄露** —— 是否有密钥被写进会被提交的文件；
2. **文档侵权风险** —— `data/documents/` 下的文档是否适合公开；
3. **运行时产物** —— `data/chroma/`、`data/uploads/` 等是否会被误提交。

实测（示例数据集）结果为：全部文档判定为低风险，未发现阻塞项。

---

## 仓库结构建议

`portfolio.md` 里给出的原则：

- 求职材料（简历、面试问答、演示脚本）**不进公开仓库** —— 项目里的 `resume/` 已被 `.gitignore` 排除；
- 运行时产物（向量库、上传文件、评测报告）不进仓库；
- 示例文档要么是虚构数据，要么是不受著作权保护的法规全文，并在 `NOTICE` 中说明来源。

    本项目用于技术学习与作品集展示，不公开部署在线服务。
    示例文档为虚构数据或不受著作权保护的法规全文。
    项目不代表任何厂商官方口径，不构成维修或保养建议。

=== "效果声明"

    **不是**准确率、召回率、QPS 或性能基准，也未与任何系统对比。
