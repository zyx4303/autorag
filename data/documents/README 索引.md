## 关键速查

### 汽车三包核心数字（法规原文口径）

- **包修期**：不低于 3 年或 60,000 公里（以先到者为准）
- **三包有效期**：不低于 2 年或 50,000 公里（以先到者为准）
- **主要零部件可换**：60 日或 3,000 公里内，发动机/变速器/动力电池/驱动电机主要零件出现质量问题
- **7 日内可退换**：需更换发动机/变速器/动力电池/驱动电机或其主要零部件
- **60 日或 3,000 公里内可退换**：转向失效、制动失效、车身开裂、燃油泄漏、动力电池起火
- **累计退换条件**：严重安全故障修 2 次未排除 / 核心总成换 2 次仍不能用 / 同一主要零部件换 2 次仍不能用 / 累计修理超 30 日或同一问题修 4 次
- **使用补偿系数** n ≤ 0.5%
- **修理记录保存** ≥ 6 年

### 故障码首字母含义

| 字母 | 系统 |
|---|---|
| P | 动力总成（发动机 / 变速箱） |
| B | 车身（空调 / 安全气囊 / 门锁等） |
| C | 底盘（ABS / 悬架 / 转向） |
| U | 网络通讯（CAN / LIN 总线） |
