# 示例车企 B · DTC 故障码总列表（虚构数据 · 可自由使用）

> **重要说明：本文件为虚构的演示数据，不对应任何真实车企、车型或平台。**
> 文件中的模块代号（SRS / BCM / ATC / PDC / PEPS / TBOX / FVCM / GATEWAY）、
> FTB 子码与故障描述均为**为演示 RAG 检索而构造的示例**，请勿用于真实诊断。
> 真实车辆的故障码请以对应车型的官方维修资料为准。
>
> **用途**：本文件用于展示本项目的文档切分（表格原子块）与检索能力，
> 覆盖 B（车身）/ C（底盘）/ U（网络通讯）三类非动力总成故障码。

---

## 一、故障码结构说明

示例车企 B 的 DTC 由 **一位字母 + 四位十六进制数字** 组成，部分码附带 **FTB（Fault Type Byte，故障类型字节）**，
用于区分同一码下的具体失效模式。

| 位置 | 含义 |
|---|---|
| 首字母 | **P** = 动力总成；**B** = 车身系统；**C** = 底盘系统；**U** = 网络通讯系统 |
| 第二、三位 | 所属系统分组（见下表） |
| 第四、五位 | 具体故障序号 |
| FTB | 故障类型：00=一般故障，02=对地短路，39=内部电子故障，92=参数超范围，96=内部故障 |

### 系统分组一览

| 模块代号 | 中文名称 | 覆盖功能 |
|---|---|---|
| SRS | 安全气囊系统 | 气囊、安全带预紧、碰撞传感器 |
| BCM | 车身控制模块 | 灯光、门锁、雨刮、后视镜 |
| ATC | 自动空调系统 | 压缩机、鼓风机、温度传感器 |
| PDC | 驻车辅助系统 | 倒车雷达、摄像头 |
| PEPS | 无钥匙进入与启动 | 智能钥匙、一键启动 |
| TBOX | 远程信息处理终端 | 车联网、远程控制、SIM 通信 |
| FVCM | 前视摄像头模块 | 车道保持、自动远光 |
| GATEWAY | 网关 | CAN/LIN 总线路由 |
