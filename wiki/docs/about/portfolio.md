# 作为作品集使用

本项目的定位是**本地演示 + 代码仓库**，不公开部署服务。

!!! info "为什么不公开部署"
    公开提供文档检索属于信息网络传播行为，需要先确认文档授权范围；
    国内网站在线服务还涉及备案成本。所以选择"可本地复现 + 代码公开"这条路线。

---

## 怎么演示

三条命令，不配 Key 也能先看到检索链路：

```bash
docker compose up            # 或本地 uvicorn app.main:app
python scripts/preflight.py  # 启动前自检，一条命令定位环境问题
```

演示顺序建议按这个来：

1. 先跑 `preflight.py`，说明环境是否真的就绪，而不是"应该能跑"
2. 问一个能答的问题，展示引用角标与依据列表
3. 问一个知识库没有的问题，展示拒答与确认渠道
4. 打开 `/guard`，展示文档变更后的失效清单

第 3 步最容易加分：多数 RAG demo 走到这一步会编一个答案出来。
