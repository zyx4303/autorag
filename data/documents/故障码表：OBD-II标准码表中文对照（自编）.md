# OBD-II 标准故障码表（中文对照 · 自编）

> **说明**：OBD-II（On-Board Diagnostics II）故障码体系由 SAE J2012 / ISO 15031-6 等公开技术标准定义，
> P0xxx 通用码的**码号与含义属于公开技术事实**（不受著作权保护）。
> 本文件的**中文描述为本项目自行组织的措辞**，用于演示 RAG 检索，
> 不抄录任何第三方码表的译文。真实诊断请以对应车型的官方维修资料为准。

OBD 是车载诊断系统（On-Board Diagnostics）的缩写。1996 年及以后在美国销售的轻型汽车
必须配备 OBD-II 系统，通过标准化故障码帮助定位排放与动力总成相关问题。

---

## 一、故障码结构说明

OBD-II 故障码由 **1 位字母 + 4 位数字** 组成，例如 **P0279**。

| 位置 | 含义 |
|---|---|
| 第 1 位（字母） | **P** = 动力总成；**B** = 车身；**C** = 底盘；**U** = 网络通讯 |
| 第 2 位 | **0** = 通用码（所有制造商一致）；**1** = 制造商自定义 |
| 第 3 位 | 子系统分类，见下表 |
| 第 4、5 位 | 具体故障序号 |

### 第三位（子系统分类）

| 值 | 子系统 |
|---|---|
| 0 | 燃油、空气或排放控制 |
| 1 | 燃油与空气计量 |
| 2 | 喷油器电路 |
| 3 | 点火系统 / 气缸失火 |
| 4 | 排放控制 |
| 5 | 车速与怠速控制 |
| 6 | 计算机与辅助输出 |
| 7 / 8 / 9 | 变速箱 |
| A / B / C | 混合动力系统 |

### P 开头故障码的区段划分

| 区段 | 系统 |
|---|---|
| P0001–P0099 | 燃油、空气或排放控制 |
| P0100–P0199 | 燃油或空气 |
| P0200–P0299 | 燃油或空气（喷油器） |
| P0300–P0399 | 点火或气缸失火 |
| P0400–P0499 | 排放控制 |
| P0500–P0599 | 车速、怠速控制 |
| P0600–P0699 | 计算机或辅助输出 |
| P0700–P0799 | 变速箱 |
| P0800–P0899 | 变速箱 |
| P0900–P0999 | 变速箱 |
| P0A00–P0AFF | 混合动力驱动 |

> **常见范围说明**：`P0` 开头为通用码；`P1` 开头为制造商自定义；
> `P2` 开头多为通用码；`P3000–P3399` 为制造商自定义，`P3400–P3FFF` 为通用码。
